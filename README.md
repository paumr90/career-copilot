# Career Copilot

Personal career management and application copilot.

## MVP principles

- Modular monolith
- PostgreSQL as the primary database
- Deterministic Rules Engine separated from the LLM
- Gmail, Drive and Calendar connectors are read-only
- No autonomous external actions
- No invented professional facts
- All important data must be traceable to a source or event
